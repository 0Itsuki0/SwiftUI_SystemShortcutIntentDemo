# SwiftUI_SystemShortcutIntentDemo

A demo of integrating RunSystemShortcutIntent to allow the user to 

- Open another app (that can be totally unrelated to ours) 
- Perform an App Shortcut
- Run any custom shortcut that they create themselves within the Shortcut app, or 
- Perform a system action.

For more details, please refer to my blog [SwiftUI: Run System Shortcuts From Widget]()
